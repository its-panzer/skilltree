# Release brief

Fictional example for the Skilltree framework.

Start with the change list and the intended audience. Distinguish shipped behavior from planned work; ask for the release status if it is missing.

## Build the story

Describe the concrete problem, then show what a person can do after this release. Use one supplied example rather than a list of abstract benefits. Keep limitations beside the relevant capability.

## Deliverable

Draft a headline, a short announcement, and a next step. Link only to supplied or verified destinations. Leave availability dates and performance numbers unresolved when no evidence supports them. Drafting an announcement does not authorize publishing it.
