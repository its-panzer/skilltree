# Clear writing

Fictional example for the Skilltree framework.

Read the draft before proposing changes. Identify its audience, central claim, and evidence. Keep the author's meaning and level of certainty.

## Editing decisions

- Replace vague nouns and unsupported superlatives with details already present in the source. Mark missing evidence instead of inventing it.
- Give each paragraph one job. Move context beside the claim it explains, and remove repeated conclusions.
- Keep distinctive phrasing when it carries meaning. Use the author's preferred spelling and terminology.

## Deliverable

Return the edited draft and a short note on material changes. Separate unresolved factual questions from style choices. If only a passage was selected, keep the edit inside that passage.
