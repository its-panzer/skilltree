# Packing list

Fictional example for the Skilltree framework.

Use the destination, duration, planned activities, and luggage constraints. Check current weather only when the travel dates make it useful.

## Packing decisions

Count reusable outfits rather than one complete outfit for every possible event. Separate essentials from optional conveniences. Account for laundry, shared items, and things supplied at the destination.

## Deliverable

Provide a grouped list with quantities and a short final-departure check. Flag unknown baggage restrictions for verification rather than assuming every carrier has the same rules.
