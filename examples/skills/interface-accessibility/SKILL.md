# Accessibility review

Fictional example for the Skilltree framework.

Define the flow and its completion point. Inspect the rendered interface as well as the implementation when both are available.

## Review decisions

Follow the primary task using the keyboard. Check control names, visible focus, input instructions, and focus after dialogs or navigation. Examine narrow layouts and text enlargement for loss of actions or context.

## Deliverable

Report concrete barriers with a reproduction and the affected task. Distinguish an observed issue from an untested assistive-technology concern. Suggest a focused repair and a way to verify it. Do not claim full accessibility compliance from this limited review.
