# Weekly plan

Fictional example for the Skilltree framework.

Start with fixed commitments, available capacity, and the outcomes that matter this week. Keep estimates visibly separate from known deadlines.

## Planning decisions

Schedule dependent work in order. Leave room for interruptions instead of assigning every available hour. Surface a tradeoff when the requested work exceeds capacity; do not hide it in an overfilled schedule.

## Deliverable

Return the week's priorities, a proposed sequence, and work deferred. State the first useful action. Treat the result as a plan until the user asks to create or change external commitments.
