# Evidence map

Fictional example for the Skilltree framework.

Extract the claims that matter to the decision. Use only the source material supplied or actually retrieved during the task.

## Mapping decisions

Distinguish direct support from partial support and inference. Record the relevant passage or data location rather than linking only to a document's homepage. Track contradictory sources alongside supporting ones.

## Deliverable

Return a claim-to-source table with a short status for each claim. Identify the smallest additional evidence needed to resolve a gap. Do not count repeated copies of one source as independent confirmation.
