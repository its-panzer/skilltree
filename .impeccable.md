## Design Context

### Users

One person collecting the skills they have created across work and personal projects, and the agents that use those skills. Find current instructions, understand related capabilities, route a request, and inspect activity.

### Brand personality

Precise, capable, tactical. Use direct language and visible evidence for routing and version choices.

### Aesthetic direction

The user's reference is a video-game skill tree: core abilities branch into specialized skills. The user explicitly chose The Division as the visual reference. Use charcoal industrial surfaces, orange interactive accents, off-white text, condensed display typography, circular skill modules, fine map grids, and stepped connection lines. Arrange core disciplines around a central network, with specialized skills cascading outward. Use original icons and geometry; do not include game logos or assets. Keep real skill counts and route state, without invented game progression. A working library opens immediately, with no marketing page.

### Design principles

1. Make the skill tree the dominant surface, with real relationships and readable labels.
2. Use progressive branch exploration so a large collection remains navigable.
3. Show routing as visible decisions, including uncertainty and failure.
4. Keep source provenance and instructions one interaction away.
5. Preserve keyboard access, mobile browsing, and reduced-motion preferences.

### Visual references

- [Original Division UI designer portfolio](<https://www.behance.net/gallery/45621303/Tom-Clancys-The-DIVISION-(User-Interface)>): icon hierarchy, compact interface typography, circular selection marks, and orange accents.
- [Ubisoft character progression guide](https://static2.ubi.com/pxm/TCTD/AG/TD2/Assets/Infographic/Character_Progression_Division2.pdf): skill platforms, variants, and related specialization abilities.

These inform the visual language; all interface graphics are original CSS, SVG geometry, and Lucide icons.
